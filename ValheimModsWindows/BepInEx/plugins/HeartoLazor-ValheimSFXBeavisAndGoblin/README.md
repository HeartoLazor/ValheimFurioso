# Valheim SFX - Beavis and Goblin

Offical port from Nexus [Hearto Lazor's](https://www.nexusmods.com/profile/heartolazor) [Valheim SFX - Beavis and Goblin](https://www.nexusmods.com/valheim/mods/797) mod into the Thunderstore format.

This mod improves ENORMOUSLY the game EXPERIENCE.
Replaces the goblin sounds with beavis and butt-head ones.

## Description
When I heard the goblin sounds, I can't stop thinking about how they will sound with the beavis and butt-head laugh. So here it is, this outstanding mod replaces the original goblin sounds with beavis and butt-head ones improving the PLAINS experience in 200%. Trust me this mod make the game better.

Video of the mod:
https://www.youtube.com/watch?v=0qno_j7ckw0

## What this mod does:
Replace the sounds: goblin_idle, goblin_alert, goblin_hit, goblin_death.

## Requirements
This mod requires the [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/v/5.4.2333/) and the [Custom Audio Location Music](https://thunderstore.io/c/valheim/p/aruberuto/CustomAudio_LocationMusic/) mod to be installed as a prerequisite.

## Manual Installation
After installing [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/v/5.4.2333/) and [Custom Audio Location Music](https://thunderstore.io/c/valheim/p/aruberuto/CustomAudio_LocationMusic/), extract this mod files into the BepInEx/plugins folder within your Valheim game directory.

## Requests
If you have any issues or more sound ideas from beavis and butt-head episodes feel free to post it in the comments with a youtube link and timestamp.

## Known Issues
If you have trouble with the Custom Audio Mod running constant audio file checks within your console menu, open the Custom Audio Config file within the BepInEx/Configs folder and turn both the Debug and the DumpInfo to = false.
